# JavaScript Arrays and Objects

This folder contains my practice of JavaScript Arrays and Objects. It covers array operations, built-in methods, object properties, object manipulation, and destructuring.

The goal is to understand how JavaScript stores, accesses, and manipulates collections of data.

---

## Topics Covered

### 1. Arrays in JavaScript
- Array Creation
- Array Constructor (`new Array()`)
- Accessing Array Elements using Index
- Array Indexing

### 2. Array Methods
- `push()`, `pop()`
- `unshift()`, `shift()`
- `includes()`, `indexOf()`
- `join()`
- `slice()` and `splice()`

### 3. Combining Arrays
- `push()` with Arrays
- `concat()`
- Spread Operator (`...`)
- Nested Arrays
- `flat(Infinity)`

### 4. Array Conversion Methods
- `Array.isArray()`
- `Array.from()`
- `Array.of()`

### 5. Objects in JavaScript
- Object Creation
- Object Properties and Values
- Dot and Bracket Notation
- Adding, Updating and Deleting Properties
- `in` Operator

### 6. Object Protection Methods
- `Object.seal()`
- `Object.freeze()`

### 7. Nested Objects
- Nested Object Creation
- Accessing Nested Object Properties

### 8. Object Methods
- `Object.keys()`
- `Object.values()`
- `Object.entries()`
- `Object.assign()`

### 9. Object Destructuring
- Basic Object Destructuring
- Renaming Variables during Destructuring

---

## Learning Objectives

- Understand JavaScript Arrays and Objects.
- Learn how to access and modify array elements.
- Practice built-in array methods.
- Understand object properties and manipulation.
- Work with nested arrays and objects.
- Learn object destructuring and useful object methods.
